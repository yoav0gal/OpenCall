# OpenCall Agent Context

This folder exists to give future AI agents fast project context without
reconstructing the entire discussion from scratch.

Start here:

1. `context/project-overview.md`
2. `context/architecture-current.md`
3. `tasks/backlog.md`
4. `tasks/spike-direct-phone-machine.md`

Current intent:

- OpenCall is a phone-to-agent calling system.
- The first target is a direct phone-to-machine prototype.
- The machine runs an always-on local bridge process.
- The bridge connects voice to Gemini Live and later to OpenClaw.
- The first milestone prioritizes learning and working end-to-end over
  production-grade infrastructure.
